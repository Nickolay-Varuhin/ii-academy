# ИИ-Академия v3 — Инструкция по обновлению

Эта версия включает **4 крупных улучшения** + накопительные правки предыдущих
итераций.

---

## Что нового в v3

### 1. Исправлены рекомендации на дашборде сотрудника
Блок «Рекомендовано для вас» теперь:
- Выбирает курсы по **слабым навыкам** конкретного пользователя
- Показывает описание, процент прогресса (по уровню навыка), длительность
- Никогда не остаётся пустым (есть фолбэк на любые доступные курсы)

Блок «Ближайшие задачи» теперь показывает **реальные задания от HR**
(из новой таблицы `assignments`), а не заглушки.

### 2. AI-функционал скрыт от HR/admin
AI-Симулятор, AI-Наставник и Карта навыков теперь доступны **только сотруднику**.
HR и админ эти пункты не видят в меню и не могут зайти по прямой ссылке
(проверка на уровне route-guard). У них свои инструменты: HR-панель,
Задания для команды, Аналитика.

### 3. Задания от HR → Сотрудникам
- HR в разделе **«Задания для команды»** (иконка планшета в меню) может:
    - Создавать задания (название, описание, сотрудник, срок, приоритет)
    - Видеть сводку: всего / в работе / выполнено / просрочено
    - Удалять свои задания
- Сотрудник в разделе **«Мои задания»** видит список назначенных ему заданий:
    - Фильтры: Все / Новые / В работе / Завершённые
    - Может нажать «Начать», потом «Завершить» (с опциональной заметкой)
    - Срочные задания подсвечиваются красной полосой слева

### 4. Все эмодзи заменены на собственные SVG-иконки
- Создан компонент `<app-icon name="..." [size]="..." color="..."/>`
- ~40 outline-иконок в единой геометрии (`stroke-width: 1.75`, 24x24 viewBox)
- Стиль нарочно не Lucide/Material/Emoji — свой, чтобы не выглядел как
  типичный ИИ-сгенерированный интерфейс
- Использован на всех страницах: login, layout, dashboard, skill-map,
  simulator, mentor, hr-dashboard, analytics, admin, assignments

### Накопительные фиксы
- Чат с AI (оптимистичное обновление + typing-эффект)
- GigaChat как основной LLM-провайдер
- Галочки «✓ Пройдено» на карточках сценариев + счётчик попыток + лучший балл
- Фикс пустого радара навыков (ViewChild setter)

## Как установить v3

### Вариант A: миграция на существующую БД (данные сохраняются)

Запусти миграцию через psql или pgAdmin:

```bash
psql -U postgres -d soft_skills -f backend/migration_v3_assignments.sql
```

Эта миграция добавит только одну таблицу `assignments` и её ENUM —
остальные данные не трогаются.

Затем:
1. Замени все файлы проекта содержимым архива
2. Перезапусти бэкенд:
   ```bash
   cd backend
   uvicorn main:app --reload --port 8000
   ```

### Вариант B: чистая установка с нуля

Только если нужно всё сбросить и иметь примеры заданий от HR в seed-данных:

```sql
-- В psql:
DROP DATABASE soft_skills;
CREATE DATABASE soft_skills;
\c soft_skills
\i backend/init_db_postgres.sql
```

После этого запусти бэкенд — `seed_database()` автоматически наполнит БД,
включая 4 примера заданий (Мария Иванова → Николай Варухин / Анна Смирнова).

### Фронтенд

Никаких миграций, просто:

```bash
cd frontend
npm install    # на случай если появились новые зависимости (их нет)
npm run start
```

Если после логина показывается что-то старое или ошибка **401** —
открой DevTools (F12) → Console → выполни:
```js
localStorage.clear()
```
и перезайди.

## Что делать если LLM не отвечает

GigaChat настроен в `.env`. Если отвалится:
- Ошибки пишутся в лог бэкенда с типом исключения
- Встроенный fallback переключает на mock-провайдер автоматически
- Приложение продолжит работать (просто диалоги будут шаблонными)

Чтобы поменять провайдера — в `backend/.env`:
```env
LLM_PROVIDER=mock      # шаблонные ответы, без API
LLM_PROVIDER=gigachat  # GigaChat от Сбера (текущая настройка)
LLM_PROVIDER=openai    # любой OpenAI-совместимый API
LLM_PROVIDER=ollama    # локальная модель (нужен установленный Ollama)
```
